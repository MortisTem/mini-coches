# Contribuir a Mini Coches

¡Gracias por ayudar con este proyecto! Sigue estas normas sencillas.

## Estrategia de ramas
- `main` es la rama estable. No trabajes directamente en ella.
- Crea una rama nueva para cada cambio, partiendo de `main`.
- Usa estos nombres para las ramas:
  - `feature/nombre` para funcionalidades nuevas (ejemplo: `feature/code-documentation`)
  - `fix/nombre` para corregir errores (ejemplo: `fix/price-filter`)

## Convenciones de commits
- Escribe mensajes cortos y claros.
- Empieza el mensaje con un tipo:
  - `feat:` una funcionalidad nueva
  - `fix:` una corrección de un error
  - `docs:` cambios en la documentación
- Ejemplo: `docs: añadir documentación JSDoc a todas las funciones`
- Haz commits pequeños, una idea por commit.

## Guía de Pull Requests
1. Sube tu rama a GitHub.
2. Abre una Pull Request hacia `main`.
3. Escribe un título y una breve descripción de lo que has cambiado.
4. Pide a alguien que revise tu código.
5. Corrige los comentarios del revisor, si los hay.
6. Haz merge de la Pull Request solo cuando esté aprobada.
