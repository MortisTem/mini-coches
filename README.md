# Mini Coches

## Descripción del proyecto
Mini Coches es una página web sencilla que muestra una lista de coches.
El usuario escribe un precio máximo y pulsa el botón "Filtrar"
para ver solo los coches que cuestan ese precio o menos.

El proyecto usa HTML y JavaScript. El código está documentado con JSDoc.

## Requisitos previos
- Un navegador web (Chrome, Firefox, Edge...)
- Git instalado en tu ordenador
- Un editor de código como Visual Studio Code (opcional)

## Instrucciones de instalación
1. Clona el repositorio:

```bash
   git clone https://github.com/MortisTem/mini-coches.git
```

2. Entra en la carpeta del proyecto:

```bash
   cd mini-coches
```

3. Abre el archivo `index.html` en tu navegador (doble clic).

4. Escribe un precio máximo en el campo y pulsa "Filtrar".

## Estructura del proyecto
- `index.html`: la página web.
- `script.js`: el código JavaScript (documentado con JSDoc).
- `README.md`: información del proyecto.
- `CONTRIBUTING.md`: normas para contribuir al proyecto.
